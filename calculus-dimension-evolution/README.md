# 📐 微積分幾何維度演進：從點到體積 (Calculus Dimension Evolution)

> **計畫名稱**：從點到體積：微積分幾何維度演進與極限視覺化互動教材

## 🌟 專案簡介
本專案為一套專為微積分教學設計的互動式數位教材。傳統微積分教學常因概念抽象（如無窮小切割、黎曼和極限、旋轉體體積）造成學習障礙。本教材透過動態視覺化與實時數學計算，讓學員能夠「看見」微積分的幾何累積原理。

## 🚀 核心功能特色
1. **0D 到 3D 維度演進**：
   - **0D (點)**：位置與微元概念 ($dx \to 0$)
   - **1D (線)**：點的累積形成長度 ($L = \int_a^b 1 dx$)
   - **2D (面)**：線段掃掠累積形成面積 ($A = \int_a^b L(x) dx$，離散黎曼和)
   - **3D (體)**：截面積沿 Z 軸堆疊形成體積 ($V = \int_0^H A(z) dz$，卡瓦列里原理，支援 360 度視角旋轉)
2. **極限與誤差視覺化**：
   - 動態調整微元數 $n$（2 至 100），直觀體驗離散逼近至連續極限。
   - 突顯黃色離散誤差區域（2D 縫隙 / 3D 輪廓虛線）。
3. **多功能教學控制**：
   - 支援 4 種幾何函數切換（常數、線性、二次、三角函數）。
   - 支援 3 種黎曼和取樣點（左端點/底端、右端點/頂端、中點）。
4. **即時 Telemetry 數據面板**：
   - 實時計算微元大小、離散和、定積分真實數值與誤差百分比。
5. **色彩語意對應**：
   - **紅色 (#dc2626)**：維度投影（長度 $f(x)$ / 截面積 $A(z)$）
   - **藍色 (#2563eb)**：微小步進向度（$\Delta x, dx, \Delta z$）
