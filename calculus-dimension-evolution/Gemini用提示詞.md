========================================
Gemini 互動教材生成指南與專用提示詞
========================================

【第一部分：AI 工具與環境設定】
為了讓 Gemini 完美生成超過 1300 行且包含複雜 3D 邏輯的程式碼，請務必按照以下建議設定：

1. 模型選用指南：
   ✅ 首選：【Gemini 3.1 Pro】+ 開啟【延伸思考】
      - 原因：此網頁包含 3D 等角投影演算法、React 狀態管理與複雜數值積分。Pro 模型處理「長篇幅、高邏輯密度」的程式碼時結構最穩定，不會寫到一半忘記變數或偷懶省略。
      - 延伸思考 (Extended Thinking)：強烈建議開啟！讓 AI 動筆前先在後台構思 2D/3D 黎曼和邏輯與 MathJax 渲染順序，大幅提升「一次生成就完美運行」的成功率。
   
   🆗 備用：【Gemini 3.8 Flash】+ 開啟【延伸思考】
      - 原因：若 Pro 模型生成速度受限，可改用此選項。雖為快速版，但在「延伸思考」的加持下，應付單一檔案網頁開發亦有出色表現。
   
   ❌ 絕對避免：【Gemini 3.5 Flash-Lite】
      - 原因：Lite 版專為極速簡單問答設計。若強迫其生成破千行程式碼，極高機率發生程式碼截斷 (Cut-off) 或邏輯崩潰。

2. 工作區設定：
   - 務必開啟「Canvas (畫布 / 程式碼工作區)」功能：
     * 即時預覽：生成完畢後可直接在介面右側渲染網頁，無需自行複製貼上。
     * 局部修改：日後若需微調（如改顏色、微元數），可直接在 Canvas 針對局部程式碼下達修改指令，不干擾主對話流。
     * 避免截斷：Canvas 模式專為長篇幅設計，輸出完整度遠高於一般對話框。

========================================

【第二部分：Gemini 專用提示詞 (請全部複製貼上)】

【任務目標】
請你扮演一位專精於「數學視覺化 (Math Visualization)」與「互動教材設計」的資深前端工程師。請為我開發一個「微積分幾何維度演進 (從點到體積)」的互動教學網頁。
整個應用程式必須封裝在單一個 HTML 檔案中，並透過 CDN 引入 React (使用 Babel 處理，不須 Webpack 打包)、Tailwind CSS (介面樣式) 以及 MathJax 3 (數學公式渲染)。

【核心規格與互動邏輯】
1. 四大維度切換 (0D, 1D, 2D, 3D)：
   - 0D (點)：展示微元奇點 (dx → 0)。
   - 1D (線)：展示點的累積形成線段 (一階積分)。紅色虛線代表當前進度，長度漸次增長。
   - 2D (面)：展示線段掃掠形成面積 (黎曼和)。動畫掃掠時，必須是「離散」黎曼和的行為：紅色掃掠線必須「完全走完」該段 Δx 的寬度後，該矩形色塊才可以整塊瞬間出現，絕對不可畫出跟著進度條連續生長的「半截矩形」。
   - 3D (體)：利用卡瓦列里原理，將 2D 面積沿 Z 軸疊加成體積。必須實作無依賴庫的簡易 3D 等角投影 (Isometric Projection) 演算法。為了避免破圖，3D 切片必須嚴格由下往上 (z=0 到 z=H) 迴圈依序繪製，並使用半透明填色疊加；支援滑鼠拖曳來 360 度旋轉視角。

2. 定積分與上下限標示 (極度重要)：
   - 所有的積分數學公式都必須是「定積分」，明確寫出上下限 (例如 \int_a^b, \int_0^H)，絕對不可寫成不定積分。
   - 畫布上必須有視覺化的上下限標示：2D 必須在 X 軸標出 x=a, x=b；3D 必須在 Z 軸標出 z=0, z=H (建議用虛線拉出到一旁，以免被 3D 立體幾何體遮擋)。

3. 核心教學控制元件 (全域)：
   - 微元數 (n) 滑桿：控制切割密度，範圍 2 到 100。用來展示離散近似到連續極限的過程。
   - 動畫進度 (Progress) 滑桿：控制 0% 到 100% 的累積掃掠動畫。播放至 100% 時需自動暫停，並將播放按鈕文字聰明地切換為「重播」。

4. 進階教學設定面板 (僅 2D/3D 模式顯示)：
   - 幾何形狀/函數切換：提供「常數 (矩形/圓柱)、線性 (梯形/圓錐台)、二次 (拋物線/拋物體)、三角 (複雜波浪/起伏花瓶)」四種形狀的動態切換，這必須同時影響 2D 的 f(x) 與 3D 的半徑 r(z)。
   - 黎曼和取樣點切換：提供「左端點(底端)、右端點(頂端)、中點」取樣，切換時需即時重繪 Canvas 上的矩形與 3D 切片高度。
   - 離散誤差面積視覺化：提供一個 Checkbox。開啟時，2D 需用黃色半透明色塊填滿矩形與平滑曲線間的縫隙；3D 需用黃色虛線繪製出平滑幾何邊緣的 4 條輔助輪廓線，以對比離散切片的落差。

5. 即時數學誤差數據面板 (Telemetry)：
   - 隨著 n 的調整，即時利用數值積分計算並顯示：(1) 當前微元大小 dx/dz (2) 離散黎曼和數值 (3) 連續定積分真實數值 (4) 兩者差距的誤差百分比。

6. 視覺化設計與色彩語意對應：
   - 全域色彩規範：嚴格將「維度投影 (如高度 f(x)、截面積 A(z))」標示為「紅色 (#dc2626)」，將「微小步進向度 (如 Δx, dx, Δz)」標示為「藍色 (#2563eb)」。
   - 此紅藍對應關係必須完美同步於：Canvas 幾何繪圖、Telemetry 數據文字，以及 MathJax 公式中。

7. MathJax 3 設定細節：
   - 必須在 <head> 中全域載入 `color` extension (`packages: {'[+]': ['color']}`，並 loader load `[tex]/color`)。
   - 處理「中英數混合」的解說文字時，請封裝一個 `<MathText>` React 元件，使用 `innerHTML` 寫入字串並呼叫 `window.MathJax.typesetPromise` 進行渲染，確保如 `\(\color{red}{f(x)}\)` 這樣的行內公式能在中文句段中被正確排版，不會原樣印出巨集文字。

【程式碼輸出要求】
請直接輸出一個完整的 HTML 檔案，包含所有 `<style>`, `<script>`, 及自幹的 3D Canvas 投影邏輯，不要有任何省略或預留區塊 (No placeholders)。畫面必須乾淨、專業，具備學術儀表板的高級質感。
