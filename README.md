# 📚 Learning Hub (數位學習與互動教具資源庫)

歡迎來到 **Learning Hub**！本倉庫收錄個人開發與設計的各類互動式數位教材、教學工具以及 AI 提示詞 (Prompts)。

## 📁 教材專案列表

### 1. 📐 微積分幾何維度演進 (Calculus Dimension Evolution)
- **目錄路徑**: [`/calculus-dimension-evolution`](./calculus-dimension-evolution/)
- **線上展示 (GitHub Pages)**: [點此體驗互動網頁](https://KaitoW2230.github.io/learning-hub/calculus-dimension-evolution/)
- **簡介**: 單一檔案互動式 HTML5 教學網頁，展現微積分從 0D (點位置)、1D (線段累積)、2D (黎曼和面積) 到 3D (卡瓦列里切片體積) 的幾何累積過程。支援即時誤差計算、四種函數切換、黎曼和取樣選擇與 3D 視角旋轉。
- **AI 提示詞指南**: 提供可用於 Google Gemini 的完整 Prompt 與 AI 工具設定指南 (`Gemini用提示詞.md`)。

## 🛠️ 技術棧

- **Visualization**: HTML5 Canvas (2D / 3D Isometric Engine)
- **Math Engine**: MathJax 3
